# Ascendum Document Bot Project

## Steps to Run the Document Bot Project

### -> Clone the repo

### -> Navigate to Django_projects (cd Ascendum_Demo\Django_Projects)

### -> Install Dependencies 

    pip install -r requirements.txt

### -> Run the command
    python manage.py runserver

### -> navigate to the http://localhost:8000/query (query endpoint for testing in local)

## Questions to Ask for the Document Bot

### The Bot is trained on the financial document, so please ask the query only related to Finance.

### Example Queries :

#### 1. The Three Basic Areas of Study in Finance?
#### 2. What are assets and liabilities?
#### 3. Explain working capital management?
#### 4. What is The Impact of Digitization?
